# Simple Solutions

Our goal is to make launching on BeeZee as simple as possible. We are actively building apps that any project can deploy and configure to look and feel like their own — so every community gets a polished, ready-made set of tools instead of starting from scratch.

Paired with the ability to use your own token for fees, an app on BeeZee can feel less like a shared network and more like a blockchain built for your project alone.
