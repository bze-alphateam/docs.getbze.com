# Cross-Chain Transfers

Move BZE and the tokens created on BeeZee to and from other connected blockchains, freely and without asking permission. We are continuously working on new cross-chain connections, so the list of chains you can reach will keep expanding well beyond what is available today.

A token brought in from another chain is treated as a first-class asset here — once it has a liquidity pool with BZE, it can serve as a fee token just like one created natively.

{% hint style="info" %}
**For example.** Bring a token in from another chain, trade it on the BeeZee DEX, then send it back out whenever you like — moving it as freely as you would BZE.
{% endhint %}

## When a token is retired

Occasionally a token is wound down on the chain it comes from, as happened with **USDC.n** from Noble. BeeZee can then close new deposits of that token, while still letting you send it back out at any time. If a transfer is refused, the tokens return to your address on the sending chain.
