# Overview

BeeZee (BZE) is a community-driven blockchain built to make decentralized tools simple to use. Rather than chasing complexity, the project focuses on a handful of practical, self-serve solutions — trading, staking, token creation, and more — that anyone can use straight from a wallet, without middlemen.

## A community-driven ecosystem

BZE is built and governed by its community. There is no central gatekeeper: token holders propose and vote on the changes that shape the network, so the direction of the project reflects the people who actually use it.

The aim is an ecosystem where decentralized solutions are approachable — where creating a token, trading it, or earning staking rewards takes a few clicks instead of technical expertise.

## Built on proven technology

BZE is a Proof-of-Stake blockchain built with the Cosmos SDK. That foundation gives it:

* **An eco-friendly network** — Proof of Stake secures the chain without energy-hungry mining.
* **Fast, low-cost transactions** — quick finality and small fees suited to everyday use.
* **Interoperability** — as part of the Cosmos ecosystem, BZE can connect and move assets across other chains.

## What you can do with BZE

The ecosystem is a set of simple apps, each covered in its own section of these docs:

* **Trade** on the native decentralized exchange.
* **Stake** your BZE to help secure the network and earn rewards.
* **Create tokens** with the Token Factory — no coding required.
* **Burn** tokens and take part in community burn events.
* **Govern** the network by proposing and voting on changes.

The sections that follow walk through each of these, step by step.
