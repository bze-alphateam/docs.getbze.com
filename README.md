# Welcome to BeeZee

<figure><picture><source srcset=".gitbook/assets/Solid Positive@3x.png" media="(prefers-color-scheme: dark)"><img src=".gitbook/assets/Solid Negative@3x.png" alt="BeeZee"></picture><figcaption></figcaption></figure>

BeeZee (BZE) is a community-driven blockchain that makes decentralized tools simple. Trade, stake, burn, launch your own token and give it a home, all from a wallet you control, with no sign-up and no middleman holding your funds.

These docs show you how, one app at a time, in plain language.

## Start here

New to BeeZee? Three steps get you going:

1. **Get a wallet and connect it.** We recommend Keplr; Leap and WalletConnect work too. See [Connecting a Wallet](using-the-apps/connecting-a-wallet.md).
2. **Get a little BZE** for the network fees. The quickest way is **Buy BZE** in any app's wallet panel. See [Buying BZE](using-the-apps/buying-bze.md).
3. **Pick an app** below and follow its guide.
