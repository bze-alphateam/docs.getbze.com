# Overview

CoinTrunk is a self-custodial wallet for the BeeZee network. It holds BZE and the tokens created on BeeZee and lets you send and receive directly — your keys stay on your own device, with no account to sign up for.

What makes CoinTrunk stand out is that it adapts to the token you use: for a token that qualifies, the wallet takes on that token's name and look, so a community can give its members a wallet that feels entirely their own. By default, it wears its own CoinTrunk look.

{% hint style="info" %}
CoinTrunk's browser extension is still in development. Availability and features will be announced as it gets closer to release.
{% endhint %}
