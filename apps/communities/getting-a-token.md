# Getting a Token

Found a project you want to join? You don't have to go hunting for it on an exchange. Right on a token's page in the [Communities app](https://communities.getbze.com), you can get the token without leaving — so joining a community is as simple as visiting its page.

## Buying the token

If you already hold BZE, getting the community's token is one quick swap. The token page shows a small buy panel where you:

1. **Enter how much you want to spend** in BZE.
2. See a **live quote** — the **expected amount** of the token you'll receive.
3. Check the **price impact** — how much your own purchase nudges the price. Smaller is better; a large number usually means the pool is small relative to your trade.
4. Set your **slippage** — a safety buffer. If the price moves against you by more than you allow between quoting and settling, the swap is cancelled instead of going through at a bad rate.

Confirm in your wallet and the token lands in your BeeZee wallet.

Don't hold any BZE yet? You can bring in funds from another network first, then swap into the token.

{% hint style="info" %}
**This appears only when it can work well.** The buy panel shows up when the token has a healthy **liquidity pool paired with BZE** — a shared pot the swap can trade against. If a project hasn't set one up yet, the option is simply hidden, and you'd get the token another way (for example, on the DEX if a market exists).
{% endhint %}

## Paying fees in the community's token

Open the **settings** on a token page and you may find a **"pay fees in this token"** toggle. Turn it on and this app collects its network fees in that community's token instead of BZE — so you can take part in everything a project offers without ever needing to hold BZE.

It's a small switch with a big effect: using a community's app starts to feel like using the community's own network, with its token paying for everything along the way. As with buying, this only appears when the token qualifies — it needs that BZE-paired liquidity pool behind it. Network staking itself always stays in BZE, which keeps the chain secure.

## A window into the token's burns

A token's page also surfaces its **burn stats** — how many tokens have been **burned in total**, when the **next burn** is due, and a **history** of past burns. Burning permanently removes tokens from circulation, so these figures are a transparency signal: an at-a-glance way to see how a project manages its supply over time.
