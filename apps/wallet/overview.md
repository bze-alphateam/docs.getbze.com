# Overview

This is a self-custodial wallet built to be brandable. Rather than being tied to one brand, it can be set up around a specific token — taking on that token's name and look — so a project can give its community a wallet that feels entirely its own.

Users get a simple, familiar way to hold and use that token, while the project gets a ready-made wallet without building one from scratch. It is a natural fit for communities that launch their own token on BeeZee.

{% hint style="info" %}
This wallet is still in development. Details, including its final name, will be announced closer to release.
{% endhint %}
