# BZE Explorer

The BZE Explorer is the window onto everything happening on BeeZee: every block, transaction, account, token, validator and governance proposal, explained in plain words. It is read-only, so you never connect a wallet. You look things up, and when you want to act, it sends you to the right BZE app.

[**Open the BZE Explorer →**](https://explorer.getbze.com/)
