# Assets Directory

The **Assets** page is BeeZee's token directory — a searchable list of every coin and token on the network. It's the best place to look something up before you trade it.

## Browsing tokens

Search for any token, or scroll the full list. At the top you'll see counts that give you a feel for the whole network:

* **Total** — every token on BeeZee.
* **Native** — tokens created here on BeeZee.
* **Community-created** — tokens launched by projects and communities using Token Factory.
* **Bridged** — tokens that originated on another blockchain and were moved in.

Each token in the list shows its **price**, its **24-hour change**, a **verified badge** where the token has been checked, and its **type** so you can tell at a glance where it came from.

## Looking at a single token

Open any token for the full picture:

* **Supply** and **volume** — how much exists and how much is trading.
* **Where it came from** — for a community-created token, that includes the **creator**, so you can see who's behind it.
* **Markets & pools** — the order-book markets and liquidity pools where the token trades, with a tap-through to go trade it.

This detail is what makes the Assets page such a handy vetting tool. Before you swap for a token you don't recognise, a quick look tells you whether it's **verified**, who created it, and how much real trading is happening around it.

{% hint style="warning" %}
A **verified** badge is a helpful signal, not a guarantee of value. An **unverified** token isn't necessarily bad — but it's worth a closer look. Check the creator, the trading volume, and where it's paired before you commit, and never trade more than you're comfortable with.
{% endhint %}

{% hint style="success" %}
**For example.** Someone spots a token called **$PAGE** and wants to make sure it's the book club's real one before buying. They open it in Assets, see the **verified** badge, recognise the creator, and confirm it trades in the $PAGE–BZE pool they expected — then swap with confidence.
{% endhint %}
