# Overview

The CoinTrunk Extension is a self-custodial browser wallet for the BeeZee network. It safely holds BZE and the tokens created on BeeZee — you can receive and send coins, check your balances, and switch between the tokens you hold — and your keys stay on your own device, with no account to sign up for.

What makes it stand out is that it adapts to the token you use: for a token that qualifies, the wallet takes on that token's name and look, so a community can give its members a wallet that feels entirely their own. By default, it wears its own CoinTrunk look. If the token you're using can't pay network fees right now — because its pool doesn't hold enough BZE — the wallet shows a calm heads-up, and you can still pay fees in BZE.

{% hint style="info" %}
The CoinTrunk Extension isn't publicly available yet, so you can't install it today. Until then, connect one of the supported wallets to the BeeZee apps.
{% endhint %}
