# Token Factory

Token Factory is the app for creating your own token on BeeZee and growing it into a community: no coding required. Pick what you want to build, answer a few short steps, check everything before you sign, and the app suggests what to do next.

[**Open Token Factory →**](https://factory.getbze.com/)
