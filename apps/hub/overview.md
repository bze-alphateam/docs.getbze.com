# Overview

BZE Hub is a desktop application for BeeZee, currently under development. It runs a small local node on your own PC, so your computer connects to the network directly instead of going through public apps or a browser.

That means more independence and privacy: you interact with the blockchain using software you run yourself, rather than depending on a third-party website being online. The goal is to bring the everyday BeeZee actions — managing your wallet, staking, trading and more — into a single desktop app backed by your own connection to the network.

{% hint style="info" %}
BZE Hub is still in development. Features and availability will be announced as it gets closer to release.
{% endhint %}
